# Практическая работа № 4 — формы и localStorage

Автор: Хамидов Дамир Маъруфович, ЭФБО-17-25. Индивидуальный вариант: 8.

Приложение продолжает ПР3: добавляет форму создания и редактирования задач, проверку полей, хранение списка в `localStorage` и сброс исходных данных. Общий и индивидуальный наборы используют разные ключи. Шесть задач варианта 8 перенесены из `practice-03/src/data.js`.

## Запуск

```bash
cd practice-04
npm start
```

Общий набор: <http://127.0.0.1:5504/>. Индивидуальный набор: <http://127.0.0.1:5504/?dataset=variant>. Браузерные проверки: <http://127.0.0.1:5504/checks.html>.

## Реализация

- `src/form-validation.js` проверяет положительный уникальный `id`, название от 1 до 100 символов после `trim()` и приоритет `low`, `medium` или `high`.
- `src/task-service.js` выполняет операции со списком без изменения входного массива.
- `src/task-storage.js` записывает JSON формата `{ version: 1, tasks: [...] }`, проверяет данные при чтении и безопасно возвращается к исходному набору при ошибке.
- `src/main.js` загружает данные при старте, сохраняет после каждой успешной операции и обновляет интерфейс.

Для контрольной №2 проверены два названия при `tasks = []`, `id = "20"`, `priority = "high"`: строка `"  Изучить localStorage  "` даёт `ok: true` и `value.title = "Изучить localStorage"`; строка из пробелов даёт `ok: false` и сообщение `errors.title`. Сохранение задачи 20 под ключом `tip-js-practice-04:demo` создаёт JSON с `version: 1`; повторное чтение возвращает задачу с теми же полями.
