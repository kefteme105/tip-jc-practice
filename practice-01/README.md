## Цель работы

Освоить запуск JavaScript, проверить преобразование типов, реализовать расчёт прогресса и план выполнения задач, а также найти ошибку с неявным преобразованием строк.

## Окружение

- Операционная система: macOS 15.7.3.
- Node.js: v24.19.0.
- Дата проверки: 12 октября 2026 года.

## Состав работы

- `index.html` подключает сценарии и содержит страницу практической работы.
- `js/hello.js` выводит ФИО, группу, номер работы и проверяет доступность `document`.
- `js/types.js` демонстрирует арифметические операции, сравнения, преобразования и оператор `typeof`.
- `js/progress.js` проверяет входные данные и рассчитывает прогресс выполнения задач.
- `js/plan.js` рассчитывает число дней с учётом дневного лимита.
- `js/debug.js` демонстрирует ошибку сложения строковых значений.

## Запуск

Из папки `practice-01`:

```bash
node js/hello.js
node js/types.js
node js/progress.js
node js/plan.js
node js/debug.js
```

В браузере можно открыть `index.html`; основной вывод будет доступен в консоли разработчика.

### Преобразование типов

| Выражение | Результат | Тип | Объяснение |
|---|---:|---|---|
| `"8" + 2` | `"82"` | `string` | Оператор `+` выполняет конкатенацию со строкой. |
| `"8" - 2` | `6` | `number` | Оператор `-` преобразует строку в число. |
| `Number("8") + 2` | `10` | `number` | Явное преобразование исключает конкатенацию. |
| `"12" > "3"` | `false` | `boolean` | Две строки сравниваются лексикографически. |

### План выполнения

Для 14 задач, 4 уже выполненных и лимита 4 задачи в день остаётся 10 задач. Расчёт даёт три дня: `4 + 4 + 2`.

### Отладка

В `debug.js` значения `completedText` и `additionalText` являются строками. Поэтому `completedText + additionalText` даёт строку `"32"`, а последующее вычитание приводит к значению `-24`. Для корректного расчёта перед сложением необходимо выполнить явное преобразование:

```js
const completedTotal = Number(completedText) + Number(additionalText);
```

Тогда будет выполнено 5 задач, останется 3. Контрольная сумма цикла равна 6.
