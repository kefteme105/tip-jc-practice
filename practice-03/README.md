## Эксперименты с DOM и событиями

| № | Прогноз | Фактический результат | Объяснение |
|---:|---|---|---|
| 1. Отсутствующий элемент и коллекция | `null` и длина `0` | `null`, `0` | `querySelector` возвращает один элемент или `null`, `querySelectorAll` — коллекцию. |
| 2. `dataset` и числовой id | строка `"23"`, после `Number` число `23` | `23 string`, затем `23` | Значения `data-*` читаются строками. |
| 3. Статический `NodeList` | старая длина останется 1, новый запрос даст 2 | `1` и `2` | Результат `querySelectorAll` не обновляется автоматически. |
| 4. Строка с HTML-разметкой | теги будут показаны текстом | `<strong>Это текст, а не HTML</strong>` | Использование `textContent` предотвращает интерпретацию разметки. |
| 5. Распространение события | capture контейнера, обработчик кнопки, bubble контейнера | Фазы `1`, `3`, `3`; `target=lab-label` | `target` остаётся вложенным элементом, а `currentTarget` меняется по обработчикам. |

## Организация кода

- `task-service.js` изменяет модель задач и возвращает `ok`, данные либо ошибку.
- `task-selectors.js` формирует новый массив для фильтров `all`, `pending`, `completed`.
- `task-view.js` создаёт карточки, сводку и сообщения пустого состояния.
- `main.js` хранит `currentTasks` и `currentFilter`, делегирует клики контейнерам и вызывает `renderApp` после успешной операции.

Полный список хранится отдельно от выбранного фильтра. Сводка вычисляется по полному списку, а число «Показано» — по видимому массиву. Обработчики подписываются на постоянные контейнеры один раз, поэтому повторная отрисовка не накапливает события.

## Отладка и клавиатура

Точка останова устанавливается в `handleTaskListClick` после получения `button` и `card`. При клике по вложенной подписи кнопки `event.target` указывает на `span`, `event.currentTarget` — на контейнер списка, `card.dataset.taskId` содержит строку, а `Number(card.dataset.taskId)` — числовой идентификатор. Для действий `toggle` и `delete` вызываются функции сервиса; результат проверяется по `result.ok`.

Кнопки доступны через Tab и активируются Enter или Space. После переключения статуса фокус возвращается на кнопку той же карточки. После удаления или исчезновения карточки из фильтра фокус получает активная кнопка фильтра. Значения `777` и `4abc` отклоняются без изменения данных.
