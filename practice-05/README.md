# Практическая работа № 5 — асинхронный клиент API

Автор: Хамидов Дамир Маъруфович, ЭФБО-17-25. Индивидуальный вариант: 8.

Клиент получает задачи и категории с учебного HTTP API. Фильтры передаются в query-параметрах. Для варианта 8 используются `completed=false`, `priority=high`, `categoryId=2`.

## Запуск

```bash
cd practice-05
npm start
```

В другом терминале:

```bash
cd practice-05
npm run client
```

Учебный API доступен по адресу <http://127.0.0.1:5505/api>. Клиент варианта 8 получает задачи с id `[4, 34]`, `meta.total = 2`. Для общего контрольного запроса `{ completed: false, priority: "high" }` результат — `[4, 13, 34]`, `meta.total = 3`.

## Реализация

- `src/api-client.js` собирает URL, отправляет `GET` через `fetch`, устанавливает `Accept: application/json`, поддерживает тайм-аут и внешнюю отмену. HTTP, сетевые ошибки и неверные ответы представлены разными видами `ApiError`.
- `src/task-api.js` проверяет фильтры и структуру ответов; предоставляет `getTasks`, `getTaskById`, `getCategories`, `loadInitialData`.
- `src/main.js` выводит задачи и обрабатывает 404 от `getTaskById(999)` через `try/catch`.
