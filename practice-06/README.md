# Практическая работа № 6 — браузерный клиент API

Автор: Хамидов Дамир Маъруфович, ЭФБО-17-25. Индивидуальный вариант: 8.

Приложение получает задачи и категории с учебного API, фильтрует список на сервере и поддерживает создание, редактирование, смену статуса и удаление задач. Начальный фильтр варианта 8: `completed=false`, `priority=high`, `categoryId=2`.

## Запуск

```bash
cd practice-06
npm start
```

Приложение: <http://127.0.0.1:5506/>. Индивидуальный вариант: <http://127.0.0.1:5506/?dataset=variant>. Браузерные проверки: <http://127.0.0.1:5506/checks.html>.

## Реализация

- `src/api-client.js` поддерживает `GET`, `POST`, `PATCH`, `DELETE`, JSON-тело, ответ 204, тайм-аут и отмену запроса.
- `src/task-api.js` проверяет схемы задач и категорий, отправляет операции изменения на сервер.
- `src/app-controller.js` управляет состояниями `loading`, `ready`, `empty`, `error`, отменяет предыдущую загрузку и игнорирует устаревшие ответы. После успешной мутации повторно загружает текущую выборку.
- `src/form-validation.js` проверяет название, приоритет и категорию перед отправкой формы.
- `src/task-view.js` создаёт карточки через DOM и `textContent`, чтобы пользовательский текст не превращался в HTML.

Для контрольной №2 проверена смена статуса задачи 4 с фильтром `completed=false`: `PATCH /api/tasks/4` вернул 200, затем `GET /api/tasks?completed=false` вернул 200; задача 4 исчезла из выборки.
