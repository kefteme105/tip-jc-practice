Автор: Хамидов Дамир Маъруфович, ЭФБО-17-25. Вариант 8 сохранён.

ПР4 продолжает исходные модули ПР3; ПР5 использует предоставленный API; ПР6 добавляет изменение через API. Исходные файлы пользователя не изменены.

1. `cd practice-04 && npm start`: http://127.0.0.1:5504/ . Сбросить данные, добавить id 20, название «Изучить localStorage», high; перезагрузить.
2. В другом терминале `cd practice-05 && npm start`. Страница http://127.0.0.1:5504/examples/kr2-check.html запускает задания 1, 3, 4.
3. Остановить API ПР5 Ctrl+C. `cd practice-06 && npm start`: http://127.0.0.1:5506/ . Сбросить данные, выбрать «В работе», применить, выполнить id 4.

Для буквального соответствия требованиям отчёта открыть DevTools: Application → Local storage для задания 2 и Network для задания 5. В приложенном DOCX эти две панели заменены диагностической страницей хранилища и журналом реальных HTTP-запросов: содержимое и ответы фактические, но это не панели DevTools.

Диагностика: http://127.0.0.1:5504/examples/storage-proof.html и http://127.0.0.1:5506/?kr2=1 . Журнал регистрирует реальные ответы fetch без изменения запросов.

Выполненные проверки: ПР4 modules 27/27; ПР5 api-client 26/26; ПР6 modules 33/33.
