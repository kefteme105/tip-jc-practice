## Модель данных и организация кода

Задача содержит поля `id`, `title`, `completed` и `priority`. Идентификатор должен быть положительным безопасным целым числом, название — непустой строкой длиной до 100 символов после `trim()`, приоритет — `low`, `medium` или `high`.

- `src/data.js` хранит общий набор и индивидуальный вариант 8.
- `src/task-service.js` содержит девять чистых операций с задачами.
- `src/main.js` выполняет демонстрационный сценарий.
- `checks.js` проверяет контракты, ошибки и неизменность входных данных.

Идентификатор не равен индексу: индекс меняется при удалении и сортировке, а `id` остаётся постоянным свойством задачи. `getTaskStats` возвращает прогресс числом, чтобы результат можно было использовать в дальнейших вычислениях. При изменении задачи создаётся новый массив и новый объект изменяемой записи; остальные объекты сохраняются.
